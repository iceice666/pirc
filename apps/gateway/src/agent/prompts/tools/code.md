Run a TypeScript async function body in Bun to batch many tool calls, loop, filter or compute without round-trips. `tools.<name>(args)` returns the tool's text output (throws on tool error); `tools.call(name, args)` returns {content, details, isError}. Available: {{tools}}. `return` a JSON-serializable value; console.log output is also captured. Runs in the workspace with a timeout (default 120s, `timeout` in seconds). Prefer tools over direct fs/process access so workspace limits and hooks apply.
