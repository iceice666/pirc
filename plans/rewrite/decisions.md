# 重寫：已定的決定

[重寫](README.md) · [方向文件](../../docs/architecture/direction.md) · [盤點](inventory.md)

2026-10-20 與使用者討論 [direction.md §6](../../docs/architecture/direction.md#6-開放的決定) 的結果。編號對應 §6；「新」是盤點時新增的問題。這些是拆 plan 的前提，不是實作授權。

## 記憶與 open loops

| #   | 決定                                                                                                                                                                                                                                             |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 新  | **週期性 open loop**（每週三 18:00 開會）是**一個常駐 loop 帶 recurrence**（cron pattern + zone，沿用 `schedules/cron.rs`）。每次 fire 產生一個 wake；時間錨顯示「下次」。了結只有兩種：你說不用了、recurrence 到期。不每次 fire 後重掛新 loop。 |
| 2   | Open loop 常駐 prompt 上限 **40 件**。降級順序：沒有時間錨、最久沒被提到的先降；有時間錨的永不降。降級 = 寫進事實層帶 `was_open_loop` 標籤，房間裡出一行小字。                                                                                   |
| 5   | Per-person 事實層放在**同一張 `memory_records` 加 `scope` 欄**（`repo:<key>` / `person`），加可選 `room_id`、`face_id` 標籤。一份 FTS5 索引涵蓋 repo 與 person。偏好層另存（小、進 prompt）。                                                    |

## 頭腦與 self-wake

| #   | 決定                                                                                                                                                                                                                   |
| --- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 13  | **全域一次只跑一個 turn**：一個頭腦、一條 `LocalSet` thread。wake turn 排在 user turn 後面；user 訊息到了會搶先，被打斷的 wake 重排。單 turn 上限 10 分鐘。connector 單次讀取有 bytes 上限。記憶體靠 OM 壓縮，不另設。 |
| 3   | Self-wake 配額預設：每日 **24 次**、同時 **2 個**唯讀研究。輪詢 cadence：email 5 分、行事曆 15 分、瀏覽器來源（Moodle）60 分、workspace/dotfiles 一天一次。超過就等，不問。                                            |
| 4   | 「值得說」預設：**時間錨永遠說**（deadline 前一天也說一次）；**來源事件**只有碰到既有 open loop、或房間明確訂閱該來源才說，其餘無聲只記；**它自己排的回頭看**有發現才說。都可用偏好調。                                |
| 11  | 主持人搬家：頭腦判斷，加兩道護欄——同一話題至少 15 則訊息且命中另一個房間的範圍（來源或 linked workspace）才提議；同一話題一天最多提一次。先不做可調規則。                                                              |

## 訊息與 turn

| #   | 決定                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| --- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 16  | **Typing debounce**（使用者提議）：人常把一則話拆成幾則短訊息送。gateway 的 turn scheduler 在「最後一次按鍵或送出」起算 **3 秒**沒動靜後，才把這段期間累積的訊息當一個 user turn 交給頭腦。訊息一送就持久化、立刻出現在房間（所有裝置），只延後開 turn。client 只多送 typing 訊號。細節：（1）頭腦正在跑 turn 時送的訊息同樣 debounce，合成**一次** steer；（2）wake 要開 turn 時使用者正在打字或在 debounce 窗內 → wake 等，這就是 #13「user 搶先」的具體定義；（3）一個 batch 裡多個 `@面孔` 由頭腦看整批決定誰回；（4）秒數是偏好，預設 3；（5）有「立即送出」逃生口（Cmd+Enter / 長按送出）跳過 debounce；（6）不顯示倒數，面孔的 presence 在 turn 真的開始才變「正在想」。打到一半走掉：typing 訊號過期，3 秒後已送的訊息照樣出去。 |

## Worker 與 node

| #   | 決定                                                                                                                                                                                                                                                                                                                                                                                                     |
| --- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | 「往外送」（auto mode 新的 outbound 類別，要問）：`git push` 全部、`git send-email`；`gh pr create/merge/comment/review`、`gh issue create/comment/close`、`gh release create`、`gh gist create`、`gh api` 非 GET；`npm`/`cargo`/`pip publish`；`curl`/`wget` 帶 body 或非 GET 到非 localhost。讀（`fetch`、`pr view`、`checks`）不問。網域 allowlist 分不出 HTTPS 讀寫——接受，記進 security-decisions。 |
| 7   | Node 能力宣告：`{os, arch, gpus: [{vendor, model, count, vramMb}], browser, terminals, sandbox: {backend, status}, workspaces, load: {running, max}}`。「閒」= `running < max`。不量 CPU/記憶體。                                                                                                                                                                                                        |
| 8   | 研究模式瀏覽器：localhost 例外只含 `localhost` / `127.0.0.1` / `::1`，**不含私網 LAN**。navigate / read / scroll / screenshot 可以；`click`、`type`、檔案下載、送表單在非 localhost 都是 action。                                                                                                                                                                                                        |
| 10  | 工人可以再叫工人：**深度 1**（工人 → team/subagents，不再往下），配額沿用 team 的 4 個；只有最上層工人回報給面孔；討論串裡縮排顯示。                                                                                                                                                                                                                                                                     |
