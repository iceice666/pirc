# Mobile ↔ web parity audit (flows and UI components)

Status: findings only (2026-09-28, main@02f54f7). Nothing below is implemented.

Scope: operation flow and feature parity between `apps/web` and `apps/android`. Performance, crash and accessibility items were covered by `plans/mobile-ui-audit.md` and are not repeated. Findings come from three read-only reviews (chat flow, side panels, app shell); the high-priority rows were spot-checked against the source, including the gateway's interaction contract.

Effort: S (under an hour), M (half a day), L (a day or more). `W:` = `apps/web/src/lib/…`, `A:` = `apps/android/app/src/main/java/dev/pirc/android/…`.

## Summary

The event normaliser and reducer are faithful ports (`W:api.ts:405-540` ↔ `A:core/timeline/Events.kt:38-158`, `W:state.ts` ↔ `Events.kt:226-306`); every event web handles, Android handles. The gaps are in what the UI does with the reduced state and in the shell around it:

1. **Android parses but never renders `widgets`/`statuses`** — no goal dock, no todo dock, no status line, no jobs-at-a-glance. On the web these sit right above the composer.
2. **The session list is not live** on Android (refresh on resume / pull only), and it has no search, no empty-workspace groups, no per-workspace quick-create.
3. **Panel state is thrown away** when leaving the panels screen (VMs are scoped to the nav entry), while the web keeps every visited tab mounted.
4. Several small **composer/interaction divergences** that change what a tap does: no stop button while typing mid-run, interaction expiry ignored, confirm "No" means something different on each client.
5. **Deferred-by-plan items that now hurt on a phone**: notifications for `waiting_input`, share-sheet entry, restoring the last session on launch.

## Suggested order

**Batch 1 — S items with the biggest felt difference**

- Chat: C4 (stop while typing), C5 (interaction expiry), C6 (confirm semantics, fix on web), C3 (status line), C16 (rename → list), C17 (offline hint), O-C7 (gate actions on connection).
- Shell: S3 (empty workspace groups), S4 (group `+`), S5 (workspace → session), S8 (optimistic pin/settle), S12 (snapshot after long background), S14 (waiting ≠ error colour), O-S1 (restore last session).
- Panels: F1 (files refresh on run end), F2 (`other` entries), F13 (remove exited terminal), F15 (memory badge).

**Batch 2 — M, the docks and liveness**

- C1 goal dock, C2 todo dock, C15 jobs badge; S1 live session list (`directory=1` stream); F14 panel state at session scope; F16 non-destructive refresh + surfaced errors; F6 history merge.

**Batch 3 — larger or deferred**

- S2 search, S10 settings screen, S11 connectivity callback + reconnectNow, D2 local notifications, O-S2 share sheet, C9 tool card detail, C14 math/mermaid, O-F2 terminal switching.
